# aws-cloud-fundamentals

Documentação técnica dos laboratórios e estudos realizados durante o bootcamp **GFT Fundamentos de Cloud com AWS** na DIO.

Cada módulo cobre um serviço ou tema específico, com conceitos, exemplos práticos e anotações de erros encontrados durante o processo.

---

## Módulos

| Módulo | Conteúdo |
|---|---|
| [`Aws-Fundamentals`](./Aws-Fundamentals/) | Modelo de negócio cloud, regiões, IAM, EC2, EBS, S3, AMIs e gerenciamento de custos |
| [`Aws-cloudFormation`](./Aws-cloudFormation/) | Infraestrutura como Código com CloudFormation — templates YAML, stacks e análise de falha em deploy |
| [`aws-StepFunctions`](./aws-StepFunctions/) | Orquestração serverless com Step Functions — state machines, ASL e Workflow Studio |
| [`aws-lambda-s3`](./aws-lambda-s3/) | Integração entre Lambda e S3 — triggers, handlers, permissões IAM e boas práticas |
